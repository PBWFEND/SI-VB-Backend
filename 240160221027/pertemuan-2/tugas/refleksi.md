
# Refleksi Pertemuan 2 — JavaScript Modern

## 1. Tiga Fitur yang Dipahami

1. **Destructuring**  
   Digunakan untuk mengambil nilai dari object atau array dengan lebih ringkas.

2. **Array Methods**  
   `map()` digunakan untuk mengolah setiap elemen, `filter()` untuk menyaring data, dan `reduce()` untuk menghitung nilai keseluruhan.

3. **Promise dan Async/Await**  
   Digunakan untuk menangani proses asynchronous. `Promise.all()` memungkinkan beberapa proses dijalankan secara bersamaan dan menunggu seluruh hasilnya.

## 2. Hal yang Masih Membingungkan

Saya masih perlu memahami perbedaan antara `Promise.all()` dan menjalankan fungsi asynchronous satu per satu, terutama dalam hal waktu eksekusi dan penanganan error.

## 3. Kesimpulan

Pertemuan 2 membantu saya memahami penggunaan JavaScript modern untuk pengolahan data dan proses asynchronous. Materi ini dapat diterapkan pada pembuatan service API.
