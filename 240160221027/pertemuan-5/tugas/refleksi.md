# Refleksi Pertemuan 5

Pada pertemuan ini saya mempelajari RESTful API
menggunakan Express.js.

### Hal yang Dipelajari

1. Memahami resource dan endpoint API.
2. Memahami penggunaan method HTTP GET, POST,
   PUT, PATCH, dan DELETE.
3. Memahami route parameter dan query parameter.

### Hal yang Masih Membingungkan

Perbedaan penggunaan PUT dan PATCH serta
penerapan status code pada setiap request.

### Kesimpulan

RESTful API membantu komunikasi antara client
dan server menggunakan endpoint, method HTTP,
dan response JSON yang konsisten.
