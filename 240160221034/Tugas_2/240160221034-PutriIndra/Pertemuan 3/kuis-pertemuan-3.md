# Kuis Formatif Pertemuan 3

## 1. Apa perbedaan JavaScript di browser dan JavaScript yang dijalankan Node.js?

JavaScript di browser digunakan untuk membuat halaman web menjadi interaktif. Sedangkan Node.js digunakan untuk menjalankan JavaScript di luar browser, misalnya untuk membuat server.

## 2. Mengapa import module lokal perlu menggunakan `./` dan ekstensi `.js`?

`./` menunjukkan lokasi file di folder yang sama atau berdasarkan folder saat ini. Ekstensi `.js` digunakan untuk menunjukkan bahwa file yang diimpor adalah file JavaScript.

## 3. Apa manfaat environment variable pada konfigurasi port?

Environment variable membuat nomor port bisa diatur tanpa harus mengubah kode program.

## 4. Apa fungsi `path.join()`?

`path.join()` berfungsi untuk menggabungkan beberapa bagian alamat file atau folder menjadi satu path.

## 5. Mengapa response HTTP perlu memanggil `response.end()`?

`response.end()` digunakan untuk menandakan bahwa pengiriman response ke client sudah selesai.

## 6. Apa status code yang tepat untuk endpoint yang tidak tersedia?

Status code yang tepat adalah **404 Not Found**, yang berarti alamat atau endpoint yang diminta tidak ditemukan.
