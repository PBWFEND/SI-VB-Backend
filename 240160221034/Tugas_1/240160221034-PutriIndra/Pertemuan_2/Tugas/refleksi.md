# Refleksi Pertemuan 2

Pada Pertemuan 2 saya mempelajari beberapa fitur JavaScript modern yang digunakan dalam pengembangan backend. Tiga fitur yang paling saya rasakan manfaatnya adalah destructuring, array methods, dan async/await. Destructuring membantu saya mengambil data dari object dengan lebih singkat. Array methods seperti map, filter, dan reduce membantu saya mengolah data tanpa harus menuliskan perulangan secara manual. Async/await membantu saya memahami cara menjalankan proses yang membutuhkan waktu, walaupun saya masih perlu banyak latihan untuk memahami proses asynchronous.

Setelah mengerjakan latihan, saya mulai memahami penggunaan Promise dan Promise.all(). Saya mengetahui bahwa beberapa proses yang tidak saling bergantung dapat dijalankan secara bersamaan sehingga waktu prosesnya bisa lebih singkat.

Hal yang masih membingungkan bagi saya adalah event loop dan urutan proses synchronous dan asynchronous. Saya masih perlu latihan untuk memahami mengapa output dapat muncul dengan urutan yang berbeda ketika menggunakan setTimeout, Promise, dan async/await.
