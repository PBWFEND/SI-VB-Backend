# Refleksi Tugas 2 — Node.js Fundamentals

## 1. Hal yang Dipelajari

Melalui tugas ini, saya belajar membuat server HTTP menggunakan modul bawaan Node.js tanpa menggunakan Express. Saya juga belajar memisahkan konfigurasi aplikasi ke dalam file `config.js`, membuat respons JSON, serta mengatur beberapa endpoint menggunakan routing sederhana.

Selain itu, saya mempelajari cara membaca data mahasiswa dari file JSON secara asynchronous menggunakan modul `node:fs/promises` dan menangani kesalahan menggunakan `try/catch`.

## 2. Kendala yang Dihadapi

Kendala yang saya hadapi adalah memahami fungsi setiap bagian kode, terutama konfigurasi aplikasi, pembacaan file JSON, dan penggunaan status HTTP. Saya mengatasinya dengan mempelajari kembali kode dan melakukan pengujian pada setiap endpoint.

## 3. Pemahaman Setelah Mengerjakan Tugas

Setelah mengerjakan tugas ini, saya memahami bahwa server menerima permintaan dari pengguna, memeriksa endpoint yang diminta, kemudian mengirimkan respons sesuai kondisi. Saya juga memahami penggunaan status HTTP seperti `200 OK` untuk permintaan yang berhasil dan `404 Not Found` ketika endpoint tidak ditemukan.

## 4. Penggunaan AI

Dalam pengerjaan tugas ini, saya menggunakan ChatGPT sebagai alat bantu untuk memahami instruksi, mempelajari struktur kode, dan membantu proses debugging. Saya tetap perlu mempelajari fungsi setiap bagian kode serta menguji aplikasi agar dapat menjelaskan cara kerja program yang dibuat.

## 5. Kesimpulan

Tugas ini membantu saya memahami dasar pembuatan server menggunakan Node.js, penggunaan modul bawaan, pengelolaan endpoint HTTP, pembacaan file JSON secara asynchronous, serta penanganan error. Saya juga belajar pentingnya melakukan pengujian untuk memastikan aplikasi berjalan sesuai kebutuhan.
