## Fitur
- **Auth**: Register & Login (JWT + bcryptjs)
- **RBAC**: `admin` (CRUD) & `user` (baca & pinjam)
- **CRUD Buku & Pinjaman**: Transaksi stok otomatis (pinjam -1, kembali +1)
- **Resilience**: `AppError` terpusat, mapping error Prisma, logger JSON + redaksi password, `X-Request-Id`, validasi `.env`, graceful shutdown
- **Security**: `helmet`, CORS selektif, rate limit 100 req/15 menit, body limit 10KB, validasi input, Prisma ORM

## Teknologi
Node.js 18+ · TypeScript · Express 5 · Prisma 6 · SQLite · JWT · helmet · cors · express-rate-limit
