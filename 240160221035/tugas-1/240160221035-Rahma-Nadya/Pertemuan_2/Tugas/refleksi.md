# Refleksi Tugas 1

## 1. Async/Await

Saya jadi lebih memahami cara menjalankan proses asynchronous menggunakan `async` dan `await`. Saya juga jadi tahu bahwa proses yang membutuhkan waktu bisa ditunggu sampai selesai sebelum program melanjutkan ke proses berikutnya.

## 2. Promise.all()

Saya jadi memahami bahwa beberapa proses asynchronous yang tidak saling bergantung dapat dijalankan secara paralel. Dengan `Promise.all()`, saya bisa menjalankan dua pencarian data sekaligus dan menunggu keduanya selesai.

## 3. ES6+

Saya jadi lebih terbiasa menggunakan fitur JavaScript modern seperti arrow function, destructuring, template literal, dan `map()`. Fitur-fitur tersebut membuat penulisan kode menjadi lebih ringkas dan mudah dibaca.
