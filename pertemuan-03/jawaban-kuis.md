1. Perbedaan JavaScript di browser dan Node.js: JavaScript di browser digunakan untuk membuat halaman web menjadi interaktif, sedangkan Node.js digunakan untuk menjalankan JavaScript di luar browser, misalnya untuk membuat server dan API.

2. Mengapa module lokal menggunakan ./ dan ekstensi .js? ./ menunjukkan bahwa file berada di folder saat ini. Ekstensi .js menunjukkan bahwa file tersebut merupakan file JavaScript.

3. Manfaat environment variable pada konfigurasi port: Environment variable memungkinkan port diatur tanpa mengubah kode program, sehingga konfigurasi lebih fleksibel.

4. Fungsi path.join(): Menggabungkan beberapa bagian alamat file atau folder menjadi satu path yang sesuai dengan sistem operasi.

5. Mengapa response HTTP perlu memanggil response.end()? Untuk menandai bahwa respons dari server sudah selesai dikirim ke client.

6. Status code untuk endpoint yang tidak tersedia: 404 Not Found, yang berarti endpoint atau sumber daya yang diminta tidak ditemukan.
