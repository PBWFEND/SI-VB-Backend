# Refleksi Tugas 2

Pada tugas ini saya membuat HTTP server sederhana menggunakan Node.js tanpa menggunakan Express.js. Saya belajar membuat server menggunakan module `http` dan membuat beberapa endpoint GET seperti `/`, `/health`, dan `/students`.

Saya juga belajar memisahkan konfigurasi aplikasi ke dalam file `config.js`, seperti nama aplikasi, port, dan environment. Selain itu, saya menggunakan `readFile` secara asynchronous untuk membaca data mahasiswa dari file `students.json`, kemudian menampilkannya melalui endpoint `/students`.

Dalam pengerjaan tugas dan materi pada pertemuan 3 ini, saya masih agak kesulitan dalam memahami beberapa materi. Pada awalnya saya juga masih bingung dengan beberapa bagian kode dan bagaimana setiap bagian saling berhubungan.

Untuk membantu memahami materi, saya mencoba membaca dan mempelajari kembali materi beberapa kali serta menggunakan AI untuk menjelaskan bagian-bagian yang masih belum saya pahami dengan lebih detail. Setelah mencoba memahami dan mempraktikkannya secara langsung, saya mulai lebih mengerti bagaimana request diterima oleh server, bagaimana menentukan endpoint yang dituju, serta bagaimana response dikirim kembali kepada client.

Dari tugas ini saya jadi lebih memahami dasar pembuatan HTTP server menggunakan Node.js dan penggunaan beberapa module bawaan Node.js. Meskipun masih ada beberapa bagian yang perlu saya pelajari lagi, pengerjaan tugas ini membantu saya lebih memahami materi yang sebelumnya masih cukup membingungkan.
