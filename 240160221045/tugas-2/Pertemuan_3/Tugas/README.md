# Tugas 2 - Pertemuan 3

## Deskripsi

Project Node.js sederhana menggunakan HTTP Server bawaan Node.js.

Project ini menerapkan:
- Module ESM untuk konfigurasi aplikasi.
- Helper untuk mengirim response JSON.
- Minimal tiga endpoint GET.
- Response 404 untuk endpoint yang tidak tersedia.
- Pembacaan file JSON secara asynchronous.
- Pengujian endpoint menggunakan curl.
