
# Refleksi Tugas 2 — Express.js Dasar

Dalam pengerjaan tugas ini, saya mengembangkan Sistem Informasi Absensi Perkuliahan Mahasiswa menggunakan Express.js 5. Saya memisahkan konfigurasi aplikasi pada app.js dan proses menjalankan server pada server.js.

Saya menggunakan ChatGPT sebagai alat bantu untuk memahami routing Express, penggunaan middleware, request dan response, serta penanganan error. Saya juga meminta bantuan ketika menemukan kendala saat mengirim request POST menggunakan PowerShell. Setelah mendapatkan penjelasan, saya mencoba kembali kode tersebut dan menguji setiap endpoint melalui terminal.

Dari pengujian yang dilakukan, saya mulai memahami cara kerja GET, POST, dan PATCH, penggunaan route parameter dan query parameter, serta pentingnya validasi input. Saya juga belajar membedakan response 200, 201, 400, dan 404 sesuai kondisi request.

Melalui tugas ini, saya semakin memahami perbedaan server Node.js murni dengan Express.js dan bagaimana Express membantu membuat pengelolaan endpoint menjadi lebih terstruktur. Saya masih perlu memperdalam pemahaman mengenai middleware, pengelolaan data, dan proses pengembangan API agar dapat membuat aplikasi backend secara mandiri.
